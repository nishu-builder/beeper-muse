# Setup

Use the [Chrome-only setup guide](chrome-setup.md) for the current release.
It covers registration, public downloads, source builds, updates, and migration.
No companion app or background terminal is required during use.

If you intentionally maintain the retired Go companion (0.3–0.5), use the
[legacy guide](legacy-companion.md). Do not mix the two extensions or share an
active registration between them.
